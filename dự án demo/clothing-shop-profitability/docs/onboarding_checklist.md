# ✅ Checklist Nhận Dự Án Mới

## Thông Tin Cần Thu Thập Từ Khách

### Bước 1 — Thông tin cơ bản
- [ ] Tên shop / thương hiệu
- [ ] Sàn đang bán: Shopee / TikTok Shop / Lazada / Khác
- [ ] Kỳ phân tích mong muốn (tháng/quý)
- [ ] Số lượng sản phẩm đang bán

### Bước 2 — Dữ liệu cần nhận
- [ ] File báo cáo đơn hàng từ sàn (xuất từ Seller Center)
- [ ] Bảng giá vốn từng sản phẩm (SKU, tên, giá nhập)
- [ ] Chi phí quảng cáo trong kỳ (nếu có)
- [ ] Chi phí đóng gói ước tính / đơn hàng
- [ ] Chính sách freeship đang áp dụng

### Bước 3 — Xác nhận đầu ra
- [ ] Định dạng báo cáo: Excel / PDF / Google Slides
- [ ] Ngôn ngữ: Tiếng Việt / Tiếng Anh
- [ ] Deadline giao báo cáo
- [ ] Cần giải thích trực tiếp (call) hay gửi file?

---

## Cam Kết Bảo Mật

Trước khi nhận file, gửi cho khách đoạn xác nhận:

> *"Toàn bộ dữ liệu của bạn được bảo mật tuyệt đối, chỉ dùng cho mục đích phân tích và không chia sẻ với bên thứ ba."*
